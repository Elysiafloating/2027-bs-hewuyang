# 任务要求（task_requirements）

> 来源：`题目与任务要求总结.docx`（智能科学与技术专业统一要求 + 何雾阳专属最低要求）
> 与 `技术方案与参考文献建议.docx`（曾维老师组 V2）。

## 一、本科最低完成要求（必须逐条在论文中有对应小节/表格）

1. **建立 YOLOv8 Baseline**：YOLOv8n/s，固定输入分辨率与训练轮数，
   记录整体 mAP@0.5、mAP@0.5:0.95 及分类别 P/R。
   - 当前 Baseline 结果：mAP@0.5=0.5908，meteor R=0.9365，**star R=0.0558**。
2. **至少一种有明确动机的改进**：针对弱小目标漏检和背景虚警，
   完成至少一种改进并说明动机。
3. **定位 star 类失效原因（核心）**：目前 star 类 Recall=0.0558，必须逐一排查
   - 样本量（实例过少）
   - 目标尺度（小于下采样步长）
   - 锚框 / 标签分配（正样本几乎取不到）
   - 损失权重
   并**实现至少两种针对性措施**，分别评估每种措施的效果，**即使为负也如实写入**。
4. **虚警抑制**：针对夜空恒星静止、流星线状短时特性，以及 seagull / airplane / satellite 等干扰源，采用后处理
   （时序 / 形态学约束等）降低误检。

## 二、拓展目标（达到则更优）

- star 类 Recall 明显提升，且整体 mAP@0.5 达到合理目标
- meteor 性能不得明显下降
- 完成消融实验（两种措施的单独与组合）
- 补充 Precision / Recall / mAP@0.5:0.95 及**虚警率**（每帧误检数或 FPPI）
- 典型漏检 / 误检案例分析 + 可复现说明 + 扩充数据
- 跨相机域验证
- 多模型横向比较
- 时序虚警抑制

## 三、过程硬节点（来自老师统一要求）

- 开题材料中必须包含**数据/语料来源说明与合规说明**
- 开题后 **4 周**提交第一版 Baseline 结果表或系统架构设计（中期前硬节点）
- 定稿前按任务书**逐条核对**最低要求
- 参考文献**逐条核实真实存在**后方可引用（见 `docs/02-literature/`）

## 四、本仓库可提交 / 不提交（见根 `.gitignore`）

- 可提交：源代码、配置、小型样例数据、文献清单、实验日志、CSV 结果、图表、论文 md/tex、小型 PDF 报告
- 不提交：大体积数据集、完整权重、大量 checkpoint、.venv/Conda、build、Vivado 临时目录、node_modules、隐私数据、版权受限 PDF
