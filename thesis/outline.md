# 论文大纲（thesis/outline）

> 按学校毕业设计模板调整章节。以下为通用结构草案。

## 建议章节

1. 绪论
   - 1.1 研究背景与意义（流星观测自动化需求）
   - 1.2 国内外研究现状（目标检测 / 天文图像处理）
   - 1.3 研究内容与技术路线
   - 1.4 论文结构
2. 相关理论与技术
   - 2.1 目标检测概述（两阶段 / 单阶段）
   - 2.2 YOLO 系列（v5/v8/v11 演进）
   - 2.3 数据增强与小目标检测
3. 数据集与预处理
   - 3.1 UAEMMN 数据集介绍
   - 3.2 数据划分与标注格式
   - 3.3 预处理与增强策略
4. 方法与实现
   - 4.1 系统总体架构
   - 4.2 模型选型与配置
   - 4.3 训练策略
5. 实验与分析
   - 5.1 评价指标
   - 5.2 baseline / 对比 / 消融实验
   - 5.3 结果可视化与讨论
6. 总结与展望

## 配套目录

- `figures/`：论文用图（架构图、曲线图）
- `tables/`：论文用表（指标对比表）
- `drafts/`：各章草稿
- `references/`：参考文献（BibTeX / 引用库）
